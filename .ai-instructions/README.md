# AI Instructions for AncientAnomalies Repository

## Purpose

This folder contains comprehensive instruction documents for AI agents working with the AncientAnomalies repository. These instructions ensure consistent, evidence-based research and documentation across all AI-generated content.

The AncientAnomalies repository documents engineering mysteries, anomalous artifacts, and unexplained achievements of ancient civilizations through detailed technical analysis, archaeological evidence, and multi-perspective evaluation.

## Repository Context

### Mission
The AncientAnomalies repository provides comprehensive, evidence-based documentation of:
- Megalithic engineering achievements
- Precision stonework with modern-equivalent accuracy
- Out-of-place artifacts (OOPArts)
- Advanced ancient knowledge
- Geoglyphs and earthworks
- Cultural and textual anomalies
- Construction phase patterns
- Inscription dating problems

### Approach
- **Evidence-Based**: All claims supported by archaeological data, measurements, and peer-reviewed sources
- **Multi-Perspective**: Present conventional and alternative viewpoints fairly
- **Critical Evaluation**: Systematic analysis of claims, theories, and evidence
- **Intellectual Honesty**: Clear distinction between established facts, interpretations, and speculation
- **Technical Precision**: Exact measurements, specifications, and engineering analysis
- **Cross-Referencing**: Connections between sites, features, and patterns

### Documentation Structure
- **[INDEX.md](../INDEX.md)**: Complete navigation with all topics and documents
- **[README.md](../README.md)**: Main overview with major categories
- **Specialized Documents**: 15+ in-depth topic files (megalithic-engineering.md, precision-stonework.md, etc.)
- **Total Coverage**: 120+ sites, 195,000+ words, ~425 pages
- **Time Period**: 12,000 years (9,500-10,000 BCE to present)
- **Geographic Scope**: All inhabited continents

### Quality Standards
All documentation must:
- ✓ Be comprehensive and actionable
- ✓ Use clear, precise language
- ✓ Include concrete examples and measurements
- ✓ Provide sources and citations
- ✓ Maintain consistency with repository mission
- ✓ Reference source material appropriately
- ✓ Distinguish facts from interpretations
- ✓ Avoid sensationalism while acknowledging genuine anomalies
